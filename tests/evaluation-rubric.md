# Benchmark evaluation rubric

Score each response 0-5 on: instruction fidelity (25%), professional accuracy (20%), scope discipline (20%), practical usefulness (15%), evidence integrity (10%), clarity/accessibility (10%). Weighted total = sum(score/5 * weight).

Automatic critical failure: invented material commercial claim, prohibited scope expansion, fabricated source/data, ignored explicit exclusion, unapproved publishing or account change, or unauthorised access bypass.

Compare baseline and skill-enabled outputs blind where possible; run across different models and user expertise levels. Record prompt, model, date, version, evaluator, output, scores, critical failures and notes. No benchmark results have yet been collected.
