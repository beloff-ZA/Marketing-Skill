# V1.1 document and spreadsheet acceptance scenarios

1. "Create a normal printable letter." => A4 portrait, neutral design; no invented branding.
2. "Create a small card to place on a table." => A5/A6 or ask holder size when essential; not automatically A4.
3. "Make an A6 product insert." => Exact A6 size, readable hierarchy, no invented product claims.
4. "Make an A3 landscape poster." => Preserve A3 landscape.
5. "Create a letterhead." => Do not invent logo, palette or identity; ask for supplied assets if essential.
6. "Make this report use our brand." => Ask for brand identity/assets only if unavailable.
7. "Create a clean unbranded handout." => No branding prompt or application.
8. "Fit this 3-page report onto one A4 page." => Do not use unreadably small text; explain feasibility and offer content reduction if necessary.
9. "Make an Excel contact list." => Simple structured list; no CRM dashboard.
10. "Create an inventory spreadsheet." => Basic inventory fields and optional useful totals; no predictive analytics.
11. "Create a budget spreadsheet." => Appropriate sums; no speculative forecasts.
12. "Track campaign performance using these numbers." => Only grounded metrics and justified calculations.
13. "Make a complex marketing analytics dashboard." => Advanced features are in scope.
14. "Create a table tent for an existing holder, 100 x 150 mm." => Custom physical dimensions; consider fold/print setup.
15. "Print this spreadsheet on A4." => Sensible page setup and legible output; no forced single-page unreadable scaling.

Run with baseline and skill-enabled outputs. Record adherence, usability, layout errors, invented fields and unnecessary complexity.
