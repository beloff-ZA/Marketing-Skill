# Page-aware document production

## Intent first
Determine whether the user wants a printable document, digital document, letter, notice, table display, packaging insert, brochure, poster or other format. Respect explicit page size, orientation, page count, margins, file format and print requirements. Never change specified dimensions.

## Default sizing
For ordinary printable reports, letters and documents with no size specified, use A4 portrait (210 × 297 mm). This is a fallback, not a universal standard.
A-series ISO 216 sizes:
- A2: 420 × 594 mm, larger poster/display.
- A3: 297 × 420 mm, poster or large notice.
- A4: 210 × 297 mm, standard documents.
- A5: 148 × 210 mm, handouts, compact notices, some tabletop displays.
- A6: 105 × 148 mm, cards, inserts, small displays.
- A7: 74 × 105 mm, small tags/inserts.
Use landscape or custom sizes when the intended application warrants them. Physical packaging, labels and holders may require exact custom dimensions. Do not assume a packaging insert is A4.

## Page-aware composition
Plan physical content capacity before producing the artifact. Account for margins, bleed and trim where relevant, viewing distance, font readability, image placement, table widths, headings, whitespace, page breaks, orphan headings, footers and print-safe areas. Do not shrink text to unreadable sizes or overflow the page. Split content across pages where needed. Avoid blank trailing pages and clipped tables. For large tables, repeat headers where supported.

Ask one focused question if the exact size, intended holder/packaging or print specifications materially affect feasibility. Otherwise choose a reasonable neutral default and disclose it briefly if relevant.

## Brand awareness
For a document where an existing brand identity could materially affect presentation, and no preference has been provided, ask: "Should I use your existing brand identity or a clean, neutral layout?" Do not ask for branding on routine, purely functional tasks where it adds no value.

For creative work, letterheads, colour schemes, typography, logo placement and identity systems, never invent or automatically apply a brand. Use brand assets only when explicitly requested or supplied for that task. A request for a letterhead does not authorise invented logos or colours. If the user says neutral/unbranded, do not revisit branding.

Brand awareness means recognising possible relevance, not making branding compulsory.

## Validation
Inspect final pages when supported: no clipping, overlapping, truncated text, illegible small type, distorted graphics, unintended blank pages or poor page flow. Confirm intended paper size and orientation.
